# ReelReady icon concepts

Six original PNG concepts generated with the built-in `image_gen` tool.
The prompt set is recorded in [prompts.json](prompts.json).

| Option | Concept | Original |
| --- | --- | --- |
| 01 | Gold R / 金色 R | [PNG](01-gold-r.png) |
| 02 | Film play / 胶片播放 | [PNG](02-film-play.png) |
| 03 | Ready play / 播放与就绪勾选（当前采用） | [PNG](03-ready-play.png) |
| 04 | Blue projector / 蓝色放映机 | [PNG](04-blue-projector.png) |
| 05 | Clapperboard / 极简场记板 | [PNG](05-clapperboard.png) |
| 06 | Retro reel / 复古胶片 | [PNG](06-retro-reel.png) |

Option 03 is used for the browser favicon and navigation brand icon. The deployed
[SVG](../../../reelready/web/static/favicon.svg) is a small vector adaptation of
the selected play/checkmark motif, keeping it sharp at tab sizes without loading
the large concept PNG. The originals above are preserved unchanged.
