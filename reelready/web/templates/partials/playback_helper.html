ReelReady 在 Docker 里运行，没法直接启动这台电脑上的播放器。「播放」和「打开文件夹」由一个只监听本机的小助手代为执行，只在运行助手的这台电脑上可用。

  1. 下载助手脚本 {{ icon("download") }}reelready-helper.py
  2. 在下载目录打开终端运行（需要 Python 3.10 以上）：python reelready-helper.py
  3. 想开机自动运行且不显示窗口：改用 pythonw reelready-helper.py 建一个快捷方式，放进「启动」文件夹（Win+R 输入 shell:startup）。

脚本里含有本机专用口令，请勿分享。修改端口后需要重新下载。
